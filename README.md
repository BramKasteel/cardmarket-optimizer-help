# FAQ
## Shipping is wrong
If the shipping fees in your shopping cart are higher than expected, use our debug option.
Sometimes a shipment is more expensive, because the seller has a lot of unconfirmed sent packages.
In our debug option you can disable this seller, so that we find another.


# Privacy Policy
Summary: we collect no _personal_ data, we don't share the data with others.<br>
We only collect data necessary to compute the optimal order for you.
There will be no change in this policy.

## What do we collect
In order to optimize your order at Cardmarket, we collect from that site:

### Information about what you want to buy
Card Data:
- which cards you want to buy
- your preferences about those cards, like language, quality, etc.
- the amount of those cards you want

### Information about where you want to buy
- The country of the sellers
- The type of seller (powerseller/ private seller)
- Preferred delivery speed of the seller

### Information about the buyer
- To which country the cards should be shipped; we need this to calculate delivery fees

## What happens with this data
- This data is sent to a temporary server, which is specifically created for your order. This server does the heavy computation.
- After computation is finished (after 20 seconds), the server is tore down and all data vanishes.
